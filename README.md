# キリトル

端末の中だけで動く、動画カット＋おすすめシーン抽出アプリ（PWA）。
動画はどこにも送信しません。外部ライブラリも使っていません。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例: `kiritoru`）
2. このフォルダの中身を **そのまま全部** アップロードする（`index.html` がリポジトリの直下に来るように）
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後、`https://ユーザー名.github.io/kiritoru/` で開ける
5. Android の Chrome で開き、メニュー →「ホーム画面に追加」（ホーム画面の「ホーム画面に追加する」ボタンでも可）

ファイルを更新したときは `service-worker.js` の `VERSION` の数字を変えてから上げ直してください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（ホーム・編集画面・各タブ） |
| `css/style.css` | 見た目。色は先頭の `:root` にまとめてある |
| `js/app.js` | 起動処理、ホーム、タブ、編集ボタン、書き出し画面、自動保存 |
| `js/state.js` | プロジェクトの状態、元に戻す履歴、タイムラインの時間計算、編集操作 |
| `js/video.js` | プレビュー再生（クリップをつないで再生／候補の確認再生） |
| `js/timeline.js` | タイムラインの表示と操作（シーク、選択、端をドラッグしてトリミング、ズーム） |
| `js/frames.js` | 隠し動画からのフレーム取得、サムネイル |
| `js/audio.js` | 音量の解析 |
| `js/sceneAnalyzer.js` | 動画から音量と映像変化を取り出す（2方式） |
| `js/scoring.js` | 盛り上がり度の計算と候補選び（重みはここで調整） |
| `js/recommend.js` | 「おすすめ」タブの画面 |
| `js/export.js` | 動画の書き出し |
| `js/storage.js` | IndexedDB への保存 |
| `manifest.json` / `service-worker.js` / `icons/` | PWA |

## おすすめシーンの判定

0.5秒刻みで次の特徴を取り、動画内での相対値（中央値→0、上位5%→1）にしてから重み付きで合計します。

| 特徴 | 重み | 内容 |
|---|---|---|
| 画面の動き・変化 | 0.32 | 縮小したフレームどうしの差 |
| 大きな音・声 | 0.28 | 音量(dB) |
| 音量の急上昇 | 0.22 | 直前3秒の平均からの上昇 |
| 明るさ・色の変化 | 0.10 | 平均輝度・彩度の変化 |
| シーン切り替え | 0.08 | フレーム差の突出 |

音声が無い動画は映像だけで判定します。重みは `js/scoring.js` の `weights` で変えられます。

解析方式は2つ:

- **高速** … 音声を一括デコードし、映像は飛び飛びにシークして取得。小さめのファイル向け（自動選択では 200MB 以下、メモリ 8GB 以上の端末では 700MB 以下）
- **省メモリ** … 見えない動画を4倍速で再生しながら音と映像を同時に読む。所要時間は動画の長さの約 1/4

## 知っておくこと

- 書き出しは「再生しながら録画する」方式なので、**動画の長さと同じくらい時間がかかります**。途中で画面を閉じたり別アプリに切り替えると止まることがあります。
- MP4 で書き出せるのは H.264 録画に対応したブラウザ（最近の Chrome / Edge / Safari）だけです。非対応の場合は WebM だけが選べます。WebM は再生ソフトによってシークバーが効かないことがあります。
- 読み込める形式はブラウザ次第です。iPhone で撮った MOV（HEVC）は Android の Chrome では開けないことがあります。
- 動画本体は保存しません。再開するときは同じ動画を選び直すと、編集内容と解析結果が戻ります。
